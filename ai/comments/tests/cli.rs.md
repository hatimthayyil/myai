# tests/cli.rs

Binary tests. `Sandbox` isolates every run: `HOME`/`XDG_CONFIG_HOME` in the temp dir, `GIT_CONFIG_NOSYSTEM`, `GIT_CEILING_DIRECTORIES` at the temp dir's parent (a stray `/tmp/.git` appears from outside these tests; repo discovery must never reach it), agent/git identity env removed, and `AI_MEMORY_NAP=0` so a note never starts a background nap (a real `claude` on `PATH` would be called). Test git runs disable auto-maintenance (its `maintenance.lock` would race the "nothing written outside the store" listing).

`a_note_naps_in_the_background` turns the trigger on with a fake `claude` shell script first on `PATH`, answering every stream-json message with a fixed `result`: two 400-byte notes need a model merge, and the detached nap builds `0+2` within the deadline, recording agent `claude-code`, model `sonnet`, the script's `session_id` and the store's origin. Provenance, filters and `show` run here since only the binary reads cwd and env.

`a_chat_turn_end_to_end_with_a_fake_claude`: `ai chat` on a pipe with a fake `claude` (bash) on `PATH` that records argv, env, the system prompt file and its first message: one prime then one turn, identical argv, `DISABLE_PROMPT_CACHING` only on the prime, `dontAsk` + allowlist, `--mcp-config` pointing at this binary and memory, the sandbox HOME's CLAUDE.md last in the prompt, identical view blocks (marked only in the prime), the logged user/tool (call and result)/ai, provenance, no follow-up turn logged. Then `ai chat mcp` answers JSON-RPC over stdio on the result.

`Sandbox::fake_claude` installs both fakes the same way as the chat crate's `fake` (see `ai/comments/ai/src/rs/chat/src/session.rs.md`): `bash` resolved from `PATH` for the shebang, the executable written by a `cp` child to avoid ETXTBSY.

`Tui`: `ai chat` on a pseudo-terminal (libc `openpty`, master close-on-exec so only the test holds it), answering the cursor-position and device-attribute queries crossterm makes at startup. `a_closed_terminal_ends_the_tui` closes the master and requires an exit within 2 s (before the fix crossterm spun forever on the hung-up tty and the chat never exited); `sigterm_ends_the_tui_idle_priming_or_in_a_turn_and_restores_the_terminal` sends SIGTERM idle, while priming hangs, and while a turn hangs, and requires a clean exit that turns bracketed paste off. A failing wait SIGKILLs the child, and `Drop` kills it too, so a failure never leaves a chat behind.
