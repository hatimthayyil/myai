# zoom.rs

Spec §7.1, shared by `ai memory zoom` and the chat's zoom tool. `n = 1`: `id+0|label`, original newlines kept. Else two levels down: the nodes of level `max(l-2, 0)` under it, so four `id+n/4|text` lines, or the two or four leaves for `n` of 2 or 4 (the middle level is only a compression of those, so nothing is lost and an agent needs half the zooms); with a `Meta` (the CLI) each line gets its `dates|fields|` head after the id; the chat passes `None` and keeps the spec's format; `None` (rendered "No line id+n.") when the node itself is not built. `pages` cuts at a useful line end or UTF-8 boundary; CLI uses `PART_CHARS`, MCP caps page size to 29,000 bytes. `page` validates part numbers from 1; every byte remains reachable.
