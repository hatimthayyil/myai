# master.rs

One command builder for master and primer; stable model/effort/system/tools/MCP args. Built-ins restricted to Bash, Read, Edit, Write, Glob, Grep, WebFetch and WebSearch; dontAsk explicitly allows those plus zoom/date. No Agent/background tools. Prime alone sets DISABLE_PROMPT_CACHING=1; the real turn removes an inherited setting. Auth environment is preserved.
