# Cargo.toml

Standalone chat crate, no workspace. Reuses memory storage/compaction/Claude process primitives; clap for CLI, signal-hook for terminal signals, jiff for local dates, serde_json for stream/MCP protocol. TUI: ratatui 0.30 without default features (`crossterm` backend, `scrolling-regions` for history inserts; crossterm 0.29 through `ratatui::crossterm`), unicode-width/unicode-segmentation for layout, pulldown-cmark for markdown, syntect (default syntaxes and themes, pure-Rust `regex-fancy`, no onig C build) for code. No test-only dependencies: the flake runs this crate's tests against a copy of the root `Cargo.lock`, which never locks a path crate's dev-dependencies, so screen tests compare `TestBackend` text directly instead of using insta. Fake scripts only in tests. Shared root target directory selected by CARGO_TARGET_DIR.
